# IoMT Anomaly Detection System

## Project Overview
This project is an IoMT (Internet of Medical Things) based anomaly detection system developed using Machine Learning and Flask. The system detects abnormal healthcare and network activities using multiple machine learning algorithms. The project aims to improve healthcare security and identify anomalous behavior from medical and network datasets.

## Features
- Machine Learning based anomaly detection
- Flask web application
- User-friendly prediction interface
- Healthcare and network data analysis
- Multiple ML algorithm implementation
- Real-time prediction support

## Technologies Used

## How to Run the Project

### Clone Repository
```bash
git clone https://github.com/KrishnaPriya-hash/IOMT-Anomaly-Detection.git
```

### Install Required Packages
```bash
pip install -r requirements.txt
```

### Run Flask Application
```bash
python Main.py
```

### Open in Browser
```text
http://127.0.0.1:5000/
```
